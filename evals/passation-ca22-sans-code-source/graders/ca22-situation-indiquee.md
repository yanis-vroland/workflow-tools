CA22 : l'outil est lancé dans un répertoire sans code source.

Réussite si le dernier message indique clairement que le répertoire ne
contient pas de code source (ou est vide) et qu'aucun dossier de passation n'a
été écrit. Échec si le message prétend avoir produit un dossier.
