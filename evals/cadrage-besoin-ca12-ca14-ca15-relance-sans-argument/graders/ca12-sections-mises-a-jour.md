004-CA12. Le livrable précédent laissait la plateforme « non déterminée, voir Q03 » ; la réponse saisie à la main à Q03 est : « Application mobile Android pour les techniciens, utilisable hors connexion ; les dispatchers utilisent un navigateur sur PC. »

- Q03 figure toujours dans « Questions au client », avec cette réponse inchangée.
- « Contraintes » (ou « Besoins fonctionnels ») intègre désormais cette réponse : application mobile Android hors connexion pour les techniciens, navigateur sur PC pour les dispatchers, avec pour source « réponse saisie à la question Q03 ».
- L'hypothèse qui dépendait de Q03 (dispatchers sur PC depuis un navigateur) n'est plus présentée comme une hypothèse à valider.

Échoue si l'un de ces points est faux.
