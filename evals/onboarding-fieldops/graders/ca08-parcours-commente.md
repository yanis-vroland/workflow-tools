CA8 : dans la section « Se repérer dans le code ».

Réussite si toutes les affirmations suivantes sont vraies :
1. Le parcours est une liste numérotée unique de 5 à 10 fichiers, dans l'ordre
   de lecture conseillé.
2. Le premier fichier est un point d'entrée de l'application.
3. Chaque fichier est cité par son chemin relatif à la racine du projet, et ce
   chemin existe dans FieldOps (ex. `src/api/server.ts`, `src/domain/types.ts`,
   `src/api/routes/interventions.ts`, `mobile/lib/main.dart`).
4. Chaque fichier est suivi d'une phrase qui dit ce qu'on y apprend.
