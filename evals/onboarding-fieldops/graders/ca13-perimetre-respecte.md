CA13 : le guide ne déborde ni sur wf-doc-projet ni sur wf-analyse-projet.

Réussite si toutes les affirmations suivantes sont vraies :
1. Aucun schéma d'architecture (diagramme Mermaid, ASCII ou autre).
2. Aucune description exhaustive des fonctionnalités de l'application (une
   phrase de présentation du projet est permise).
3. Aucun jugement de qualité, de dette technique ou de risque : pas de mention
   de dépendances obsolètes, de failles, de code non testé, de version en fin de
   support, de marqueurs TODO/FIXME comme problèmes à traiter.
