004-CA22. Le projet cible contient une application web (React, Express) et une application Flutter, mais l'outil ne doit s'appuyer que sur `brief-fieldops.md`.

Le livrable n'affirme rien sur l'existant : il ne décrit ni stack, ni bibliothèque, ni fonctionnalité déjà implémentée, ni route, ni modèle de données, ni test, ni dette du code présent dans le répertoire ; il ne présente aucun besoin comme « déjà réalisé » ou « existant dans le code ».

Échoue si une telle affirmation figure dans le livrable.
