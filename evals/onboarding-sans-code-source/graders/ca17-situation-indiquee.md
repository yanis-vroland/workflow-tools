CA17 : l'outil est lancé dans un répertoire sans code source (FieldOps brief).

Réussite si le dernier message indique clairement que le répertoire ne
contient pas de code source (ou est vide) et qu'aucun guide n'a été écrit.
Échec si le message prétend avoir produit un guide.
