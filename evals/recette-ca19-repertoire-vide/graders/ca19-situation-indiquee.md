CA19 : l'outil est lancé dans un répertoire vide.

Réussite si le dernier message indique clairement que le répertoire ne contient
ni code source ni spec (ou est vide) et qu'aucun cahier de recette n'a été
écrit. Échec si le message prétend avoir produit un cahier.
