CA13 : dans la section « Points d'attention ».

Réussite si toutes les affirmations suivantes sont vraies :
1. Chaque point est un fait vérifiable, cité avec le fichier qui l'établit
   (marqueurs, écart entre README et code, test désactivé, adresse écrite en
   dur).
2. Aucun niveau de risque, de gravité ou de priorité n'est attribué (ni
   « critique », « élevé », « faible », ni pictogramme de couleur).
3. Aucune estimation d'effort ou de délai de reprise, aucune note.
4. Aucun jugement de qualité ou de dette sans fait cité (ex. « code fragile »,
   « dette importante », « dépendances obsolètes à mettre à jour »).
