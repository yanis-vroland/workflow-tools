005-CA22 (et CA15 par contraste). Le projet ne contient aucun code source : seulement des documents (brief, notes) et le livrable de cadrage.

Le livrable ne prétend pas avoir pris en compte du code existant, ne cite aucun fichier de code (`.ts`, `.dart`, `.js`…) ni dossier de code (`src/`, `lib/`…), et ne présente aucune tâche comme une modification ou une reprise d'un existant.

Échoue si une telle affirmation figure dans le livrable.
