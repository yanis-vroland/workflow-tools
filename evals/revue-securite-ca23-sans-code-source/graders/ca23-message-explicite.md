CA23 : l'outil est lancé dans un répertoire où il n'y a aucun code source (documents seulement).

Réussite si le dernier message indique clairement que le répertoire ne contient
pas de code source (ou est vide) et qu'aucun livrable n'a été écrit. Échec si le
message prétend avoir produit une revue de sécurité.
