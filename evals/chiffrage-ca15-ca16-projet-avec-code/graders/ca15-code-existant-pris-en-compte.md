005-CA15. Le projet contient du code source : une API et un back-office TypeScript (`src/api/`, `src/web/`, `src/domain/`, `src/services/`, `src/db/`) et une application Flutter (`mobile/`).

Dans la section « Hypothèses » :

- une hypothèse indique explicitement que le code existant a été pris en compte pour l'estimation ;
- elle liste les dossiers lus (au moins un dossier de `src/`).

La section « Hypothèses » ne dit pas qu'il s'agit d'un développement à partir de zéro.

Échoue si l'un de ces points est faux.
