005-CA15. Le projet a pour dossiers de code `src/` (avec `src/api/`, `src/web/`, `src/domain/`, `src/services/`, `src/db/`, `src/jobs/`) et `mobile/` (application Flutter, sans rapport avec les évolutions demandées).

- Chaque dossier listé comme non lu figure dans « Points non déterminés ».
- `mobile/` figure soit parmi les dossiers lus listés dans « Hypothèses », soit parmi les dossiers non lus de « Points non déterminés » (il n'est pas passé sous silence).
- Aucun dossier n'est présenté à la fois comme lu et comme non lu.

Échoue si l'un de ces points est faux.
