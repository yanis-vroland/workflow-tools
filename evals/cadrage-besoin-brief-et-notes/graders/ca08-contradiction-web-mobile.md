004-CA8. Les sources se contredisent : `brief-fieldops.md` demande un outil web utilisé depuis un navigateur, sans installation sur les postes ni sur les téléphones ; `notes-appel.md` rapporte que les techniciens doivent saisir leurs comptes rendus sur une application mobile installée sur leur téléphone, utilisable hors connexion.

- « Questions au client » contient une question sur cette contradiction, qui cite les deux sources (`brief-fieldops.md` et `notes-appel.md`).
- Ni « Besoins fonctionnels » ni « Contraintes » ne retiennent l'une des deux versions : aucune de ces sections n'affirme que l'outil sera uniquement web sans installation, ni qu'il y aura une application mobile installée ou un mode hors connexion pour les techniciens. Une mention qui renvoie explicitement à la question ouverte est permise.

Échoue si l'un de ces points est faux.
